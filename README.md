# jobyaari-blog-system
A Full Stack Blog Management System Developed using PHP, MySQL ,HTML ,CSS, and Bootstrap.
## Features
- Admin Login
- Add/Edit/Delete Blogs
- Category Filters
- Responsive Design
- Image Upload
- Rich Text Editor

## Technologies Used
- PHP
- MySQL
- Bootstrap
- HTML/CSS
- CKEditor

## Run Project
1. Install XAMPP
2. Import database.sql
3. Place folder inside htdocs
4. Start Apache & MySQL
5. Open localhost/project-folder
